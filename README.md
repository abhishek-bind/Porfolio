A clean, responsive, and editorial-themed personal portfolio website showcasing my academic journey, technical skills, and web development projects. Built to connect with recruiters, hiring managers, and collaborators for entry-level roles, internships, and remote opportunities.

---

## ✨ Key Features

- **Dark & Gold Editorial UI:** Modern typography paired with a high-contrast dark theme (`#111111` & warm gold accents) for clear readability.
- **Fully Responsive Layout:** Optimized across desktop, tablet, and mobile devices with smooth navigation.
- **Selected Work Showcase:** Direct access to live demos and GitHub repositories for my featured projects:
  1. **Pritam Studio Website** — Luxury wedding photography & cinematography business website with local SEO and service packages.
  2. **Bilingual Quote Generator** — Interactive English & Hindi quote web app featuring Text-to-Speech (Web Speech API) and LocalStorage favorites.
  3. **Login & Registration System** — Responsive authentication UI connected with a PHP & MySQL backend.
- **Working Contact Form (Formspree AJAX):** Asynchronous contact form submission with instant inline feedback—no page reload or external mail app required.

---

## 🛠️ Tech Stack

- **Front-End:** HTML5, CSS3, JavaScript (ES6+)
- **Styling & Icons:** Custom CSS Grid/Flexbox, Google Fonts, Font Awesome
- **Form Handling:** Formspree REST API (Fetch / AJAX)
- **Hosting & Version Control:** Git, GitHub, GitHub Pages
